GETTING STARTED

Deploy ABS

The quickest route is to fork the repository and deploy it as a Render Web Service.

1. Get the project

Fork ABS on GitHub to your own GitHub account. Keep the repository public or private according to your needs.

2. Configure the service

ABS requires MC_HOST and MC_USERNAME. The included render.yaml provides the remaining defaults.

3. Deploy

On Render, create a Web Service from your fork. The repository already defines the Node.js runtime, build command and start command.

4. Check the bot

Open your deployed service. The root endpoint provides a status dashboard, /api/status returns JSON, and /health provides a lightweight health check.
