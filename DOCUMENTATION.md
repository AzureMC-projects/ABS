# ABS Documentation Catalog

Welcome to the **ABS (Azures Bot Service)** documentation catalog.

## Public website

The repository now includes a static documentation website in [docs](docs/), with:

- Home and project overview
- Getting Started
- Configuration reference
- Render deployment
- Troubleshooting
- Video tutorial
- ABS Control Panel

The video tutorial is available at https://www.youtube.com/watch?v=n96qdvqEUWo.

## GitHub Pages

The repository includes a GitHub Actions workflow at .github/workflows/pages.yml that publishes docs/ to GitHub Pages.

If Pages has not been enabled yet, open **Settings → Pages** in the repository and choose **GitHub Actions** as the build/deployment source. Once enabled, changes to docs/ on main deploy automatically.

The existing ABS Control Panel is preserved as docs/control-panel.html.
