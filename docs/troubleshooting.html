TROUBLESHOOTING

When something goes wrong

The bot does not connect

Check MC_HOST, MC_USERNAME and MC_PORT. Then inspect the deployment logs for the first Minecraft error.

The bot keeps reconnecting

Confirm the server is reachable, the account can join, and the Minecraft version is compatible. ABS will retry according to RECONNECT_MS.

The bot is kicked or banned

ABS cannot bypass server rules, kicks, bans, authentication requirements or network restrictions. Only use automated clients where the server permits them.

The service is healthy but the bot is offline

Review the latest connection, kick, error and reconnect messages in your host logs. Compare the live dashboard with /health and /api/status.
