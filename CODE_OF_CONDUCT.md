# Code of Conduct

## Our standard

ABS is intended to be a welcoming open-source project. Contributors are expected to be respectful, constructive, and professional.

Unacceptable behavior includes harassment, personal attacks, discrimination, deliberate disruption, and publishing private information without permission.

## Enforcement

Project maintainers may remove comments, close issues or pull requests, or restrict participation when behavior violates this code of conduct.

For serious or sensitive concerns, use the private reporting guidance in [SECURITY.md](SECURITY.md) where appropriate.

## Scope

This code of conduct applies to project spaces and interactions when someone is representing or participating in ABS.
