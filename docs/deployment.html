DEPLOYMENT

Deploy with Render

ABS includes a render.yaml blueprint configured for a Node.js Web Service.

Service settings

  • Runtime: Node.js
  • Build: npm install
  • Start: npm start
  • Required variables: MC_HOST and MC_USERNAME

After deployment

Check the Render logs for connection messages. Visit your service URL to see the status dashboard. The health endpoint is /health.

Important limitation

ABS can reconnect while its process is running, but no application can guarantee a persistent Minecraft connection if the host stops the service or the Minecraft server rejects the connection.
