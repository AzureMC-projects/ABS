# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private security reporting features for this repository when available. If private reporting is unavailable, contact the repository maintainers privately before publishing details.

## What to include

Please provide:

- A clear description of the issue.
- Steps to reproduce it.
- The affected version or commit.
- Any relevant logs or proof of concept that can be shared safely.

Never include passwords, access tokens, session tokens, private keys, or other credentials in a report.

## Scope

Security reports are most useful when they concern the ABS source code, its configuration handling, or dependencies used by the project.
