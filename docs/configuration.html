CONFIGURATION

Environment variables

ABS is configured through environment variables. Do not commit credentials or secrets to Git.

VariableRequiredDefaultPurpose
MC_HOSTYes—Minecraft server hostname or IP
MC_PORTNo25565Minecraft server port
MC_USERNAMEYes—Bot username
MC_AUTHNoofflineMineflayer authentication mode
MC_VERSIONNoautoMinecraft protocol version
RECONNECT_MSNo5000Reconnect delay
WALK_INTERVAL_MSNo1000Movement update interval

Authentication

For Microsoft authentication, set MC_AUTH=microsoft and follow the authentication flow required by your deployment environment.

Monitoring

Use / for the live dashboard, /api/status for JSON service information and /health for a lightweight health response.
