# Compatibility

## Primary target

ABS is primarily developed and tested for:

- **Paper 26.3**

## Other server software

Vanilla, Spigot, Paper forks, proxies, and other Minecraft versions may behave differently.

Compatibility is not guaranteed unless explicitly documented by the project.

## Skin compatibility

ABS-Skins depends on Paper's player profile and texture APIs. Proxy networks and custom authentication/profile systems can affect how a skin is propagated to connected clients.

## Reporting compatibility issues

Include:

- Minecraft version
- Server software and exact version
- Proxy software, if any
- ABS version or commit
- ABS-Skins version, if applicable
- relevant logs
- reproduction steps

Do not post credentials, tokens, passwords, or private server information.
