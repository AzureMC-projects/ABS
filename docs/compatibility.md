# Server Compatibility

## Primary target

ABS is primarily made for **Paper 26.3**.

| Server software | Version | Support status |
|---|---|---|
| Paper | 26.3 | Primary target |
| Other Paper versions | Varies | Not the primary test target |
| Vanilla | Varies | Not currently a primary target |
| Spigot / forks | Varies | Not currently a primary target |

Compatibility can also depend on the Minecraft protocol version, server configuration, plugins, authentication mode, and hosting environment.

### Reporting compatibility problems

When reporting a compatibility issue, include:

- Minecraft version
- Paper/server version
- Relevant plugins if known
- The behavior you expected
- The behavior you observed
- Relevant ABS logs

Never include passwords, access tokens, private server credentials, or other secrets in an issue.
