# ABS Wiki

Welcome to the **Azures Bot Service (ABS)** wiki.

ABS is a Render-friendly Minecraft bot built with Node.js and Mineflayer. This wiki collects practical information for installing, configuring, operating, customizing, and troubleshooting ABS.

## Current focus

The primary ABS target is **Paper 26.3**. Current project work includes reliable connection/reconnection, automatic respawn, continuous movement, Render deployment, health/status endpoints, and the ABS-Skins Paper plugin.

> This wiki describes the project as it develops. Release-specific behavior may change before stable releases.
